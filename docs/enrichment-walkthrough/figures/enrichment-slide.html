The enrichment flow on one slide

A simplified version of the enrichment map, sized for a presentation. Six steps, the source behind every step, how far to trust each value, and what happens after the API.

Putting it in PowerPoint

  1. Save enrichment-slide.svg (sent to you alongside this page).
  2. In PowerPoint: Insert → Pictures → This Device, pick the file, and stretch it to fill a 16:9 slide. It stays sharp at any size.
  3. To edit a word: select it, then Graphics Format → Convert to Shape. Every label becomes editable text.

Saying it in 30 seconds

A record first gets cleaned, so every value sits in the right field. Then we ask which organisation it is, registries first, and which department. If nothing matched, we read the web, but the answer must come from the pages and is checked against a registry again.

Every record then goes through Verify and Judge, where each value gets a trust level and a review flag is set only when a human is actually needed.
